# Laws of Existence - Media Uploads Directory

This directory contains all uploaded media files for the Laws of Existence website.

## Directory Structure

- `manuscript/` - Images for research content
  - `diagrams/` - Technical diagrams and flowcharts
  - `photos/` - Photographs and visual documentation
  - `charts/` - Data charts and statistical visualizations

- `data/` - Images for evidence content
  - `graphs/` - Data graphs and analytics
  - `screenshots/` - Screen captures and interface images
  - `documents/` - Document images and scans

- `timeline/` - Images for timeline events
  - `events/` - Event-specific images
  - `organizations/` - Organization logos and images
  - `milestones/` - Milestone achievement images

- `map/` - Images for world map content
  - `visualizations/` - Map visualizations and overlays
  - `regions/` - Regional-specific images
  - `data/` - Map data visualizations

- `general/` - General purpose images
  - `icons/` - Icons and small graphics
  - `backgrounds/` - Background images
  - `logos/` - Logos and branding materials

## File Naming Conventions

- Use lowercase letters and hyphens
- Include descriptive names
- Avoid spaces in filenames
- Use appropriate file extensions (.jpg, .png, .svg, .webp)

Example: `transcendental-method-diagram.png`

## Supported Formats

- JPEG (.jpg, .jpeg) - For photographs
- PNG (.png) - For graphics with transparency
- SVG (.svg) - For scalable vector graphics
- WebP (.webp) - For optimized web images

## Usage

Images are automatically organized by the CMS based on the collection type:
- Research content → `manuscript/`
- Evidence content → `data/`
- Timeline content → `timeline/`
- World Map content → `map/`
